# StoryWeave AI — 3D Folio Bookshop & Investigative Studio

An interactive 3D WebGL bookshop landing experience and cinematic writer studio designed for investigative fiction, narrative world-building, and character relationship tracking.

## ✨ Highlights

- **3D Folio Bookshop Hero**: A high-fidelity Three.js WebGL curved book carousel with dynamic page textures, ambient lighting, smooth hover springs, and Libre Caslon Display typography.
- **Dedicated Writing Studio**: Decoupled studio with full-page looping background atmosphere, typewriter soundscapes, and comprehensive story architecture.
- **Investigative Crime Board**: Interactive evidence wall with parchment background, pinned suspect polaroids, and realistic red thread connections with dynamic catenary sag.
- **Character Dossier Portal**: Centered physical investigation case files with stamp certifications, psychological profiles, and click rate-limiting protection.

## 🚀 Quick Start

### Option 1: Standalone Folio Server (Pre-bundled)
```bash
node serve.cjs
```
- Open [http://localhost:3000/](http://localhost:3000/) for the 3D Bookshop Hero.
- Open [http://localhost:3000/studio.html](http://localhost:3000/studio.html) for the Investigation Studio.

### Option 2: Full Development Environment
```bash
cd story_ui_repo/frontend
npm install
npm run dev
```
Navigate to `http://localhost:5173/` in your browser.
